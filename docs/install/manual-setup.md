# Manual install

## Install

Copy the [`skills/use-claude-code-subagents`](../../skills/use-claude-code-subagents) folder, including `references/`, to:

- `~/.cursor/skills/` for every project, or
- `<project>/.cursor/skills/` for one project.

You also need Claude Code installed and signed in. See [Requirements](../README.md#requirements).

## Verify

Open **Customize, Skills** in Cursor. Then follow [Verify it works](../guides/usage.md#verify-it-works).

## Update and remove

Update: copy the folder again. Remove: delete the folder.
